# Recording checklist

- Confirm source status and database durability before recording.
- Use actual route, candidate and report responses from the running app.
- Keep attribution visible and avoid displaying personal information.
- Label any submitted observation as a test report; remove it using an authorized maintenance path after recording.
- Record desktop and mobile layouts, keyboard focus, loading and unavailable-source behavior.
- Inspect the full recording and confirm the voiceover does not call a route safe or a report verified.
