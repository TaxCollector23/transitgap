# Final shots and recording instructions

1. Record the real production URL, not a staged fake site. Hide personal browser data and credentials.
2. Capture desktop route selection, real stop, profile request, mapped route and text directions.
3. Capture the documented/possible comparison and source-linked inspection-impact output. Read live values; do not substitute historical numbers if data changes.
4. Capture a clearly labeled synthetic algorithm fixture and passing test output. State AI/student contributions accurately.
5. Include a real observation only if actually supplied by a human. Otherwise use the reproducible test result.
6. End with a plain statement of model/data limits.

Playwright screenshots and failure traces are local generated QA artifacts, not a completed competition video. The student must record narration, confirm eligibility/deadline, upload a public video, and retain the real submission receipt.
