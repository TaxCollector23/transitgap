# Consent-based user test script

Run only with an informed, willing participant and required school/guardian approval. Do not ask for diagnosis or retain identifying details. Participation can stop at any time. Record anonymous task outcomes and direct feedback only with permission.

## Intro

“We are evaluating TransitGap, not you. It models local walking-network evidence near transit stops. It does not guarantee an accessible route. You can stop at any time. May I take anonymous notes about task completion and usability?”

## Tasks

1. Open the landing page and explain, in your own words, what the app can and cannot tell you.
2. Open the planner, select a starting point and VTA stop, and request a route.
3. Find the textual directions and one source/evidence detail without relying only on map color.
4. Open access gaps, select a stop/profile/time, compare scenarios, and explain “documented” versus “possible.”

## Capture

Record task completion (yes/no), time only if consented, confusing labels, errors, assistive technology used if volunteered, and participant-chosen suggestions. Do not write invented quotes. Summarize aggregate counts only after real sessions; label small convenience samples and do not generalize them to all disabled riders.
