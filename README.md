# TransitGap

**[Open the site](https://transitgap.vercel.app/) · [Open the map](https://transitgap.vercel.app/app) **


TransitGap is an open-source application that helps people find walking routes to public transit based on their accessibility needs. It identifies potential barriers and highlights missing accessibility information.

Social Impact:

TransitGap aims to make public transportation easier to navigate for people with disabilities, stroller users, and others with mobility needs. It also helps communities identify accessibility data gaps and infrastructure issues that need attention.

Tech Stack:

Frontend: React, TypeScript, Vite, Tailwind CSS

Backend: Python, FastAPI

Routing: NetworkX, OSMnx, Dijkstra, A*

Maps & Data: MapLibre, OpenStreetMap, VTA GTFS
