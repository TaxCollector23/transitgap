# Field-check protocol

Use this only with a willing adult/student researcher, public locations, safe conditions, and any required school/guardian approval. Never enter traffic, private property, or a closed construction area. Do not collect names, faces, precise home locations, or health details. Stop if conditions are unsafe.

1. Choose a public crossing or pedestrian segment from a source-linked study result. Record the OSM way/stop ID and map link before visiting.
2. Record date, local time, weather if relevant, exact public segment endpoints, and the observation method. Do not imply an observation covers a whole block or route.
3. Record only visible facts: curb ramp presence on each corner, detectable warning presence, measured clear width and method, surface condition, crossing control/signal cues, obstruction, and sidewalk continuity. Use “not observed” or “not measured” instead of guessing.
4. Add a photo only when allowed and frame infrastructure without identifiable people or license plates. Store consent and photo separately from public notes.
5. Compare each observation with the source tags. Label disagreement as a dated observation, not an automatic correction or proof of code compliance.
6. Have a second reviewer check the transcription. Keep source timestamp, observation timestamp, and review timestamp distinct.

This protocol is not a safety inspection, ADA compliance determination, or substitute for accessibility expertise.
